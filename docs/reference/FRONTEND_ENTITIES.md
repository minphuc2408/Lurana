# Entity frontend — Lunarra

Tài liệu tra cứu cho frontend/backend: model/DTO, nguồn dữ liệu và nơi sở hữu state. Bảng entity được đối chiếu ngày **17/10/2026**; phần ownership/lifecycle được hợp nhất từ guide và đối chiếu lại ngày **19/10/2026**. [API contract](API_CONTRACT.md) định nghĩa request/response, [Database](DATABASE_DESIGN.md) định nghĩa lưu trữ và [PROJECT_STATUS.md](../PROJECT_STATUS.md) giữ trạng thái nghiệm thu/triển khai.

Root `shared/` chứa constants/Zod schemas dùng chung Worker và frontend; `src/shared/` chứa UI/helpers. Shop service chuyển ProductApiDto thành Product để trình bày; không fallback fixture khi API lỗi. CatalogProvider giữ catalog và snapshot detail trong memory. Luồng active dùng số nguyên VND, formatter chung và timezone Asia/Ho_Chi_Minh; locale chỉ đổi nhãn/định dạng, giữ nguyên dữ liệu khách nhập.

Route tree và provider scope thuộc [ARCHITECTURE](../ARCHITECTURE.md#router-và-provider-ownership). Customer auth/profile/orders/wishlist tài khoản/request cùng admin customers/settings/notifications vẫn deferred; bật VITE_ENABLE_CUSTOMER_AUTH đơn lẻ không vượt cờ customerApiReady=false.

Các hàng ghi **legacy/deferred** dưới đây mô tả source được giữ lại, không phải tính năng đang hoạt động.

## Ownership và vòng đời dữ liệu

- **CatalogProvider:** boot categories + featured page; cache memory hợp nhất theo product ID qua `rememberProducts`/`rememberProduct`, `loadVariants` khôi phục snapshot giỏ. Shop giữ response trang riêng trong `useProducts`, không lọc toàn catalog ở client hoặc tải tuần tự mọi trang. Detail tải theo slug; không fixture fallback. Provider scope ở [ARCHITECTURE](../ARCHITECTURE.md#router-và-provider-ownership), response metadata ở [API contract](API_CONTRACT.md#get-apiproductspage1qcategorycodepriceallsortfeaturedfeatured1).
- **CartProvider:** localStorage `lunara.cart.v1` chỉ `{version:1,lines:[{variantId,quantity}]}` qua Zod, tối đa15 dòng/20 mỗi dòng và max_quantity API. Restore dùng bounded by-variants, không phụ thuộc trang Shop đang mở. Chỉ persist sau restore thành công; lỗi read giữ dữ liệu đã lưu, expose `hydrationError/retryHydration` cho Cart/Home/detail. Tên/ảnh/size/giá là snapshot API; quote cập nhật giá/phí/tổng, không giữ tồn.
- **WishlistProvider:** Product snapshots và open state chỉ ở memory, chia sẻ card/detail/header qua route; reload mất. Khác wishlist tài khoản deferred. UI/resize/đóng panel ở [luồng detail](../ARCHITECTURE.md#chi-tiết-sản-phẩm-và-hoa-yêu-thích); không tạo storage hoặc API wishlist song song.
- **CheckoutFlowProvider/useCodCheckout:** giữ form, địa chỉ, lựa chọn thanh toán/consent và ý định đặt hàng trong memory giữa /cart và /checkout; rời nhóm route hoặc reload xóa draft. UUID gắn payload và giữ khi retry cùng ý định; token Turnstile lấy mới mỗi attempt, nằm ngoài fingerprint. Chỉ server thành công mới xác nhận đơn và xóa cart. Reload giữa request chưa rõ kết quả làm mất intent: cần tra đơn, không coi reload là retry an toàn. [Luồng giao diện](../features/CHECKOUT_UI.md).
- **useQuoteCart:** sở hữu province/ward/method và quote. Tỉnh/phường đến từ public delivery options, không import snapshot JSON. Đổi tỉnh xóa phường; quote chỉ chạy khi địa chỉ đã chọn hợp lệ, debounce 350 ms và hủy read cũ. Danh mục D1 đầy đủ chỉ phục vụ admin; [quy tắc địa chỉ](../features/DELIVERY_ADDRESS.md).
- **AuthProvider:** chỉ giữ session UI trong memory, cookie HttpOnly do server quản lý. Đọc session cũ không được ghi đè trạng thái sau login/logout/401; role client không cấp quyền API.
- **Admin hooks:** giữ draft riêng với snapshot server; PATCH chỉ dirty fields. Tab/filter/page/size chỉ ở memory: Orders/dashboard/products/zones phân trang server; size/filter/search dùng chung query limit/offset, đổi tiêu chí về trang1 và clamp trang cuối sau mutation. Kho chỉ đọc variants/ảnh của trang; GET variant theo ID dùng cho recheck. `useAdminPresentation` chia trang variants/gallery/items/timeline; đổi trang không xóa draft keyed theo variant ID. Popup giữ các field form trong DOM, lỗi constraint mở đúng tab/cỡ chứa trường lỗi đầu tiên; gallery vẫn chỉ áp dụng bằng Save. Nếu stock_delta có kết quả không rõ, xóa delta và khóa row tới khi GET kiểm lại thành công, không tự lặp delta có thể đã áp dụng.
- **Dòng kho/phí:** Hai cột đầu là STT/No. (chỉ số thứ tự) và Thao tác/Actions (icon xóa/sửa). SKU bật chế độ sửa rồi lưu bằng icon check/hủy bằng X; draft keyed theo ID giữ qua trang và có nhãn chưa lưu. Xóa có xác nhận; server chặn cỡ cuối/SKU trong đơn mở. Zone có công tắc active riêng; DELETE khác tắt trạng thái. `useAdminExcelImport` chia sẻ vòng đời file/preview/lỗi/pending cho sản phẩm và phí, chỉ memory, không tự retry kết quả chưa rõ. [API](API_CONTRACT.md#nhập-phí-giao-hàng-excel) sở hữu giới hạn/atomic import.
- **Nhập Excel kho:** `useAdminProductImport` giữ file base64/preview/lỗi/kết quả chỉ trong memory; chọn file → API kiểm toàn bộ → xem sản phẩm/SKU → xác nhận nhập. Thành công tải lại kho, giữ draft variant cũ và reload catalog. Lỗi NETWORK/TIMEOUT/BAD_RESPONSE/INTERNAL khóa xác nhận và yêu cầu đóng/tải lại kho đối chiếu slug; không tự retry. Nút Tải ảnh trước Sửa mở tab gallery và focus input ảnh, dùng lại draft/upload/Save hiện có. Sản phẩm nhập chưa có ảnh vẫn sửa text được; create form thường vẫn cần ảnh. [API Excel](API_CONTRACT.md#nhập-sản-phẩm-excel) sở hữu columns/limits/transaction.
- **Lookup:** form/token/kết quả chỉ ở memory. DTO public và admin cùng đọc snapshot đơn nhưng có projection/quyền riêng; [chức năng tra đơn](../features/ORDER_TRACKING.md) mô tả đầy đủ hành vi UI.
- **Locale:** localStorage `lunara_language` là preference riêng; ưu tiên giá trị đã lưu, rồi browser EN/VI, English fallback. `name_vi`/alias `name_vn` không đổi ID, currency hoặc nội dung người dùng.
- **Tên hiển thị:** API active trả `name_en/name_vi`; `name_vn` là alias FE legacy. `getLocalizedName` ưu tiên vi → vn → en → legacy cho VI, en → legacy → vi → vn cho EN; cart/order giữ snapshot song ngữ. Search catalog/stock/order mẫu hỗ trợ tên Việt và bỏ dấu. Giá chỉ format ở display boundary; currency VND, timezone `Asia/Ho_Chi_Minh` và dữ liệu khách nhập không đổi theo locale.
- **Theme preference:** chỉ lưu theme ID qua `lunara.theme.v1`; bootstrap/compatibility có owner tại [DESIGN_SYSTEM](../ui-ux/DESIGN_SYSTEM.md#bootstrap-persistence-và-compatibility), độc lập locale và dữ liệu nghiệp vụ.

Cấu hình tại [i18n/config.ts](../../src/shared/i18n/config.ts), resources bundle trong `src/shared/i18n/locales/en|vi/` theo namespace; không gọi backend/dịch vụ dịch để đổi UI. `keySeparator/nsSeparator=false` cho phép dùng copy có dấu chấm/hai chấm làm key. Message có count dùng plural suffix/interpolation của i18next, không nối `s` trong JSX. Thiếu key tiếng Việt fallback English; storage bị chặn vẫn đổi locale trong phiên. `html.lang` cập nhật để typography và portal kế thừa đúng [design system](../ui-ux/DESIGN_SYSTEM.md#typography-theo-locale).

Các fixture user/profile/customer, đơn legacy, wishlist tài khoản, request và dashboard chưa dùng chung ID hoặc API. Không nhập chúng vào D1 hoặc dùng chúng để xác nhận thao tác thật. Hero/category minh họa là asset riêng; ảnh và mô tả sản phẩm thuộc catalog/DB.

Khoảng trống của source deferred được chuyển từ guide: Profile Edit chưa đồng bộ AuthProvider; Signup chỉ preview; wizard request chưa nối AdminRequests và model budget chưa có input. Settings Save local chưa đổi cấu hình toàn app; chart/revenue/top products còn chờ API. Đây là ngữ cảnh legacy để tiếp tục phát triển, không mô tả chức năng customer đang active hoặc quyết định tự bật chúng.
