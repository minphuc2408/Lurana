# Entity đang có trong frontend Lunara

**Cập nhật:** 14/10/2026 · **Phase 0–3:** DONE local · **Phase 4:** DONE local (9/9 tiêu chí) · **Phase 5:** PARTIAL · **Phase 6:** PLANNED. **UI:** D1 catalog/cart/quote preview, legacy features ẩn. **Backend:** catalog/delivery/quote, COD/tồn/idempotency/lookup/transition và auth/admin đã có local. [Hiện trạng](PROJECT_STATUS.md) · [Stack](TECH_STACK.md) · [Schema canonical](../migrations/0001_mvp.sql). UI **Lunara**, repo **Lurana**.

**Giữ hiện tại:** English mặc định/fallback, EN/VI JSON, VND/giờ VN, cart variant/localStorage; code legacy PHP/settings ẩn. COD guest và auth/admin đã có backend; phần tiếp theo là UI checkout/lookup/login/admin Phase 5. Phase 4 dùng nguyên 10 bảng canonical, admin từ secret không dùng bảng users; `custom_requests` deferred. Các bảng `users`/`user_addresses` đã migrate local nhưng chưa có customer auth/profile API. [Nghiệm thu database](pipeline/PHASE_1_DATABASE.md).

Phase 2 trả Product/variants/images, delivery options và CartQuote theo [contract](pipeline/API_CONTRACT.md). Root `shared/constants.ts` và `shared/schemas.ts` dùng chung cho Worker/FE; `src/shared/` vẫn là thư viện UI hiện tại. Giá VND/DTO API đã adapter vào Shop service/CatalogProvider; CartProvider lưu variant IDs/quantity và lấy tổng/phí từ quote. Các model legacy trong bảng dưới giữ source nhưng không render trên các route đã ẩn. [Hướng dẫn test 5173](pipeline/PHASE_2_API_CATALOG.md#test-thủ-công-trên-host-5173).

Phase 3 trả OrderSummary/OrderDetail thật từ D1, normalize SĐT, giữ snapshot song ngữ và timeline; shared order/lookup schemas đã có. Frontend chưa có adapter/service gửi hoặc tra đơn, chưa có `/orders/track` active; không dùng các fixture order bên dưới làm kết quả API. Các dòng Product/Category/Cart là model preview active; contact/order/admin/profile/wizard/settings mô tả source legacy cần nối hoặc deferred.

Phase 4 bổ sung DTO admin có quyền: summary/status counts, order list phân trang và detail có admin_note/stock_released/actor_label, products mọi trạng thái với stock_quantity chính xác, variants và delivery-zones. Schema Zod admin nằm ở root `shared/admin-*-schemas.ts`; `/api/admin/me` chỉ trả role ADMIN, không có model tài khoản khách hay JWT trong response JSON. Các DTO này chưa có adapter/UI Phase 5. [Contract/admin](pipeline/API_CONTRACT.md) · [nghiệm thu Phase 4](pipeline/PHASE_4_ADMIN.md).

## Phần legacy và việc còn lại khi nối UI

1. User/profile/customer fixtures chưa có cùng ID và dữ liệu chung. Profile edit chưa cập nhật AuthProvider.
2. Orders khách/admin/profile/dashboard legacy là fixture độc lập; API public Phase 3 và admin Phase 4 dùng chung orders/items/history D1, có projection và quyền riêng. Còn nối UI Phase 5.
3. Request wizard không tạo record cho AdminRequests; budget hiện có trong model nhưng chưa có ô nhập.
4. Stock edit trong source admin legacy chỉ đổi state; API admin Phase 4 đã chỉnh tồn nguyên tử bằng stock_delta, UI chưa nối. Quote không giữ tồn, order API Phase 3 trừ tồn nguyên tử; UI gửi đơn chưa nối.
5. Price/total/budget có nơi numeric, có nơi chứa `₱` và dấu phẩy. Không đưa các chuỗi display này vào cột money.
6. Ngày phần lớn là chuỗi `Mar 17, 2026` hoặc `Jan 2025`; dùng timestamp/date có format tại ranh giới UI.
7. Legacy category/status/payment còn dùng English label; backend đã có code ổn định và preview category dùng DB code. Cần adapter status/payment khi nối UI order/admin; EN/VI chỉ đổi nhãn.
8. Cart active đã lưu versioned localStorage theo variant ID, reload giữ số lượng và báo giá lại. Ngôn ngữ là preference riêng, không đổi currency/timezone hoặc tên khách.
9. UI active đã dùng VND/địa chỉ tỉnh-phường; PHP/Asia/Manila còn ở source legacy ẩn. Giữ VND/giờ VN và map status uppercase của API khi nối checkout/admin, không đổi English default/fallback.
