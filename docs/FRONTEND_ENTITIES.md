# Entity đang có trong frontend Lunara

**Cập nhật:** 15/10/2026 · **Phase 0–3:** DONE local · **Phase 4:** DONE local (9/9 tiêu chí) · **Phase 5:** DONE local (6/6 tiêu chí) · **Phase 6:** IN PROGRESS (D1 remote migrate/seed/backup đã xong, chưa deploy/dữ liệu thật/nghiệm thu URL). **UI:** catalog/cart/checkout COD/xác nhận/tra đơn và đăng nhập/admin dùng API; feature chưa có API tiếp tục ẩn. **Backend:** catalog/delivery/quote, COD/tồn/idempotency/lookup/transition và auth/admin đã có local. [Hiện trạng](PROJECT_STATUS.md) · [Stack](TECH_STACK.md) · [Schema canonical](../migrations/0001_mvp.sql). UI **Lunara**, repo **Lurana**.

**Giữ hiện tại:** English mặc định/fallback, EN/VI JSON, VND/Asia/Ho_Chi_Minh, cart variant/localStorage; code legacy PHP/settings được giữ và ẩn. Phase 5 nối các API Phase 3–4, không đổi DDL hoặc package đã pin. Admin từ secret không dùng bảng users; `custom_requests` deferred. Các bảng `users`/`user_addresses` đã migrate local và remote ở Phase 6 nhưng chưa có customer auth/profile API. [Nghiệm thu database](pipeline/PHASE_1_DATABASE.md).

Phase 2 trả Product/variants/images, delivery options và CartQuote theo [contract](pipeline/API_CONTRACT.md). Root `shared/constants.ts` và `shared/schemas.ts` dùng chung cho Worker/FE; `src/shared/` vẫn là thư viện UI hiện tại. Giá VND/DTO API đã adapter vào Shop service/CatalogProvider; CartProvider lưu variant IDs/quantity và lấy tổng/phí từ quote. Các model legacy trong bảng dưới giữ source nhưng không render trên các route đã ẩn. [Hướng dẫn test 5173](pipeline/PHASE_2_API_CATALOG.md#test-thủ-công-trên-host-5173).

Phase 3 trả OrderSummary/OrderDetail thật từ D1, normalize SĐT, giữ snapshot song ngữ và timeline. `useCodCheckout` dùng cùng cart/quote, form sender/recipient/date/slot/card/note và shared order schema; chỉ gửi IDs/số lượng/thông tin giao, không gửi giá/tồn/tổng. Ý định đặt hàng có UUID v4 tạo khi vào xác nhận, giữ khi retry cùng payload, đổi khi nội dung đổi; ref chặn bấm đúp. Chỉ server 2xx mới xóa cart và hiện mã/tổng server. Form/ý định chỉ ở bộ nhớ, không persist thông tin khách. `/orders/track` dùng lookup service bằng mã + SĐT, hiển thị `OrderDetailView`; sửa thông tin tra cứu xóa kết quả cũ và hủy request đọc đang chờ.

Phase 4 bổ sung DTO admin có quyền: summary/status counts, order list phân trang và detail có admin_note/stock_released/actor_label, products mọi trạng thái với stock_quantity chính xác, variants và delivery-zones. Phase 5 dùng `admin-api.service.ts`/adapters/hooks và `AdminApi*` views; component không fetch trực tiếp. Schema Zod admin nằm ở root `shared/admin-*-schemas.ts`; `/api/admin/me` chỉ trả role ADMIN, không có tài khoản khách hay JWT trong JSON. AuthProvider khởi động bằng `/me`, login/logout bằng cookie HttpOnly; request cũ không được khôi phục session sau login/logout/401. [Contract/admin](pipeline/API_CONTRACT.md) · [nghiệm thu Phase 4](pipeline/PHASE_4_ADMIN.md).

Routes active: `/`, `/shop`, `/cart`, `/orders/track`, `/admin/login`, `/admin/dashboard`, `/admin/orders`, `/admin/stock`, `/admin/delivery-zones`; `/admin` chuyển dashboard, `/admin/products` chuyển stock. AdminRoute bọc toàn bộ `/admin/*` vận hành, API vẫn là ranh giới cấp quyền. `VITE_ENABLE_CUSTOMER_AUTH` mặc định false và còn bị chặn bởi cờ sẵn sàng API trong `shared/config/features.ts`; bật biến môi trường đơn lẻ không mở customer fixtures. Customer login/signup/my-orders/profile/wishlist, custom requests, customers/settings/notifications chưa có API vẫn ẩn; source được giữ.

## Ownership và phần còn deferred

1. User/profile/customer fixtures chưa có cùng ID và dữ liệu chung. Profile edit chưa cập nhật AuthProvider.
2. Orders khách/admin/profile/dashboard legacy là fixture độc lập và ẩn. Public lookup/admin active cùng đọc orders/items/history D1, có projection và quyền riêng; component detail dùng chung qua public feature API.
3. Request wizard không tạo record cho AdminRequests; budget hiện có trong model nhưng chưa có ô nhập.
4. Stock edit legacy chỉ đổi state và ẩn. Admin active dùng stock_delta nguyên tử; quote không giữ tồn, order API trừ tồn khi commit. Khi kết quả PATCH không rõ, row khóa và delta về 0, tự đọc lại canonical; nút Recheck phải đọc thành công mới mở lại. Giá/ngưỡng/active đã sửa nhưng chưa gửi được giữ, không lặp delta cũ.
5. Price/total/budget trong source legacy có nơi numeric, có nơi chứa `₱` và dấu phẩy. Luồng active dùng số nguyên VND và formatter chung; không đưa chuỗi display vào cột money.
6. Ngày source legacy phần lớn là chuỗi `Mar 17, 2026` hoặc `Jan 2025`; active dùng timestamp/date API và format tại ranh giới UI.
7. Legacy category/status/payment còn dùng English label. Active catalog/order/admin dùng code ổn định, EN/VI chỉ đổi nhãn; dữ liệu khách/admin nhập không dịch. Initial system timeline note được localize riêng, không đổi note người dùng.
8. Cart active đã lưu versioned localStorage theo variant ID, reload giữ số lượng và báo giá lại. Ngôn ngữ là preference riêng, không đổi currency/timezone hoặc tên khách.
9. UI active dùng VND/địa chỉ tỉnh-phường, formatter chung và thời gian Asia/Ho_Chi_Minh; PHP/Asia/Manila chỉ còn source legacy ẩn. API client chung timeout 20 giây, error-code mapping dùng EN/VI, lỗi không xóa form/cart.
